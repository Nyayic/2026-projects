# 2026 Projects

A collection of beginner-friendly coding projects for **2026**.
This repository is used as part of my teaching materials for people who are **learning programming from scratch**.

## Purpose

The goal of this repository is to help beginners:

* Practice fundamental programming concepts
* Build small, simple projects
* Learn by writing and experimenting with code

## Who This Is For

These projects are designed for:

* Complete beginners
* Students learning their first programming language
* Anyone who wants simple practice projects

## Structure

Each folder contains a small project or exercise focused on a specific concept such as:

* Basic syntax
* Variables and data types
* Control flow
* Functions
* Simple problem solving

## How to Use

1. Clone the repository
2. Open a project folder
3. Read the instructions (if provided)
4. Try solving or modifying the code
